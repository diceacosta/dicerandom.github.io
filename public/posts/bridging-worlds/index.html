Bridging Worlds, Using Hammer, Blender, and Unity Together

Date: 04-16-2025

 

 

When I first started making maps, it was in the Hammer Editor for the Source Engine. Hammer was my creative playground — fast, simple, and deeply familiar. It’s a tool built for a very specific purpose: making levels for games like Half-Life 2, Counter-Strike: Source, and Portal. For years, I thought those skills would be locked inside those games forever.

But recently, while working in Unity, I had a realization: the tools we know best can still serve us in new, modern workflows. In this post, I’ll walk you through how to take a map made in Hammer, bring it into Blender using the Plumber plugin, export it as FBX, and import it into Unity. More importantly, I’ll explain why it’s worth embracing old tools alongside new ones.

Why Start in Hammer?

If you’ve spent any time modding Source games, you probably have strong muscle memory for Hammer. You know how units feel, how to align brushes, and how to block out a layout quickly and intuitively. In many cases, I can create a level layout faster in Hammer than I can in Unity or Blender, even though those tools are more modern and powerful.

So instead of starting from scratch in a new tool, why not leverage that experience? By using what you already know, you can focus on the creative part — designing your space — without fighting a new toolset in the early stages.

The Workflow

Let’s break down the workflow, step by step.

Step 1: Build a Map in Hammer

Start by creating a simple level using the Source SDK’s Hammer Editor.

When you’re finished, save your map as a .VMF file (Valve Map Format).

Step 2: Import into Blender with Plumber

Instead of converting files externally, you can use a Blender plugin called Plumber. Plumber directly reads VMF and BSP files and imports them as clean, structured 3D scenes inside Blender — textures, materials, and all.

To use it:

  1. Install Plumber via Blender’s Add-on preferences.
  2. In Blender, go to File -> Import -> Source Engine VMF/BSP.
  3. Select your .VMF file and import.

Step 3: Unpack Textures for Export

If your map uses textures from the game, Blender will link to them internally after import. Before exporting to Unity, you need to unpack these texture files so they live on disk.

In Blender:

  1. Go to File -> External Data -> Unpack Resources.
  2. Choose Unpack All Into Files.

This will extract the textures into a folder next to your Blender project, ensuring they’re preserved when exporting to other formats.

Step 4: Export to FBX

Once everything looks good in Blender:

  1. Clean up any extra geometry or fix any minor issues.
  2. Go to File -> Export -> FBX.
  3. Export the model with appropriate settings for Unity (apply transforms, limit FBX version to 2013-2018 for safest compatibility).

Step 5: Bring it Into Unity

Open your Unity project and import the FBX file. Drag it into your Assets folder and drop it into a scene.

In Unity, you’ll probably want to:

  • Assign the unpacked textures to your materials.
  • Add colliders so your player controller can interact with the environment.
  • Adjust lighting and scaling if needed.

And just like that, your Hammer map is alive in a modern engine.

What This Teaches Us

This isn’t just a technical trick — it’s a teaching moment about creativity and workflow.

Often, we feel pressure to leave behind old tools when new ones come along. But in reality, the tools you’ve mastered are still valuable. You don’t have to start over just because the game engine is new. Workflows don’t have to be linear or conventional — they can be personal and flexible.

This process shows that your skills are transferable. The ability to quickly block out levels in Hammer can serve you well in Unity. The important thing isn’t what tool you use — it’s how you use it.

Final Thoughts

Your experience with older tools like Hammer isn’t obsolete — it’s an asset. In fact, it might be the fastest way to prototype and experiment in modern engines. By combining Hammer, Plumber, Blender, and Unity, you’re building a creative bridge between generations of technology.

So next time you’re about to dive into a new project, ask yourself: what old skills or tools could help you get started faster? The answer might surprise you.
